# Trattoria del Ponte — concept

Concept del sito della Trattoria del Ponte (Corso Sempione 99, Gallarate), a cura di Alpwise Studio. Non è il sito ufficiale.

Next.js 16 + Tailwind CSS 4. Le prenotazioni aprono WhatsApp con il messaggio già compilato. Dati, menù e orari in `app/info.ts`.

```bash
npm ci
npm run dev
```
